# proyecto_cubicador_arucos
Es un proyecto que mide las dimensiones de un objeto, utilizando ArUcos como referencias de medición.

# Análisis del proceso

## EJEMPLO DE PEDIDO
- pedido 32048472 bultos 14
- palos 5 (1 bulto)
- Cajas N4 (2 bultos)
- Cajas N2 (5 bultos)
- Cajas de paletizador código 84556 (4 bultos)
- bulto irregular (1 bulto)
- bulto irregular (1 bulto)
- pallets 2 (0 bultos) -> no se cuentan como bultos del pedido, pero si deben aparecer en detalle

## ALGORITMOS
### ALGORITMO captura_informacion_bultos_pedido
===INICIO===
- ESCANEAR QR DEL BULTO -> OBTIENE NUM_PEDIDO, NUM_BULTO
- ESCANEAR CÓDIGO DE BARRAS DEL BULTO (o código de barras personalizado para bulto irregular o palo)
- CONSULTA SI CÓDIGO EXISTE EN BASE DE DATOS

- SI CONTADOR DE BULTOS ES MENOR O IGUAL A CANTIDAD DE BULTOS DEL PEDIDO
    - SI EL CÓDIGO DE BARRAS ES "PALOS":
        - DIGITAR CANTIDAD DE PALOS (por defecto será 1)
        - OBTIENE LARGO, ALTO, ANCHO, VOLUMEN, PESO (serán las medidas en grupo, ya que es 1 bulto)
        - DIGITAR CANTIDAD DE BULTOS IGUALES (por defecto será 1)
        - GUARDA INFORMACION DEL BULTO
        - APARECE BULTO CON DATOS ABAJO EN LISTA DE BULTOS (cada bulto es editable)
        - CONTADOR DE BULTOS = CONTADOR DE BULTOS + CANTIDAD DE BULTOS IGUALES
        - VUELVE AL INICIO

    - SINO SI EL CÓDIGO DE BARRAS ES "BULTO" O SE ESCRIBIÓ "BULTO":
        - SE ABRE LA APLICACIÓN CUBICADOR EN "MODO BULTO"
            - UBICAR BULTO EN CUBICADOR, LA CÁMARA DEBE VER CLARAMENTE LARGO, ALTO, ANCHO
            - OPRIMIR BOTÓN "MEDIR"
            - OBTIENE LARGO, ALTO, ANCHO, VOLUMEN, PESO, FOTO DEL BULTO
        - DIGITAR CANTIDAD DE BULTOS IGUALES (por defecto será 1)
        - APARECE BULTO CON DATOS ABAJO EN LISTA DE BULTOS (cada bulto es editable)
        - CONTADOR DE BULTOS = CONTADOR DE BULTOS + CANTIDAD DE BULTOS IGUALES
        - VUELVE AL INICIO

    - SINO SI ES CÓDIGO DE BARRAS CAJA DE LA EMPRESA
        - OBTIENE LARGO, ALTO, ANCHO, VOLUMEN
        - DIGITAR U OBTENER PESO POR ALGÚN MEDIO
        - DIGITAR CANTIDAD DE BULTOS IGUALES (por defecto será 1)
        - GUARDA INFORMACION DEL BULTO O BULTOS IGUALES
        - APARECE BULTO O BULTOS CON DATOS ABAJO EN LISTA DE BULTOS (cada bulto es editable)
        - CONTADOR DE BULTOS = CONTADOR DE BULTOS + CANTIDAD DE BULTOS IGUALES
        - VUELVE AL INICIO

    - SINO SI ES CÓDIGO DE BARRAS PRODUCTO DE LA EMPRESA
        - OBTIENE LARGO, ALTO, ANCHO, VOLUMEN, PESO
        - DIGITAR CANTIDAD DE BULTOS IGUALES (por defecto será 1)
        - GUARDA INFORMACION DEL BULTO O BULTOS IGUALES
        - APARECE BULTO O BULTOS CON DATOS ABAJO EN LISTA DE BULTOS (cada bulto es editable)
        - CONTADOR DE BULTOS = CONTADOR DE BULTOS + CANTIDAD DE BULTOS IGUALES
        - VUELVE AL INICIO

    - SINO SI EL CÓDIGO DE BARRAS NO ESTÁ REGISTRADO
        - RECIBE NOTIFICACIÓN DE "CÓDIGO NO REGISTRADO, REGISTRE EL CÓDIGO Y VUELVA A INTENTARLO."
        - VUELVE AL INICIO

    - FIN SI
- SINO
    - APARECE MENSAJE "PEDIDO CON TODOS LOS BULTOS REGISTRADOS"
- FIN SI

- INGRESAR CANTIDAD DE PALLETS (por defecto será 0) -> AGREGARÁ CADA PALLET COMO BULTO FICTICIO
- OPRIMIR "FINALIZAR RESPALDO DE PEDIDO"
- VUELVE AL INICIO Y LIMPIA LA LISTA DE BULTOS
===FIN===

### ALGORITMO registrar_codigo_cubicador
===INICIO===
- DIGITAR CÓDIGO DEL PODUCTO
- DIGITAR NOMBRE DEL PODUCTO
- TOMAR FOTOGRAFÍA DEL PRODUCTO EN EL CUBICADOR -> OBTIENE LARGO, ALTO, ANCHO, VOLUMEN
- TOMAR FOTOGRAFÍA DEL PESO O DIGITARLO (si la báscula no se puede conectar al pc) -> OBTIENE PESO
- REVISAR SI LOS DATOS PREVIOS AL REGISTRO ESTAN CORRECTOS
- OPRIMIR BOTÓN "REGISTRAR DATOS" -> ALMACENA LARGO, ALTO, ANCHO, VOLUMEN, FOTOGRAFÍA DEL PRODUCTO
===FIN===
